# Code of conduct

Everyone is welcome to use TcTidy and to help improve it. In issues, pull requests and
every other project space:

- Be respectful and patient, and assume good intent.
- Discuss the code and the project, never the person.
- Harassment, insults, discrimination and personal attacks are not accepted, in public
  or in private.

## Reporting

To report unacceptable behavior, use GitHub's **Report content** on the comment, issue
or pull request concerned.

## Enforcement

The maintainer may edit or delete comments, lock conversations, and block anyone who
does not follow this code of conduct.
