# Third-party components of the TcTidy extension

Besides `tctidy.exe` and the crates it statically links (see `THIRD-PARTY-NOTICES.md`),
the TcTidy extension redistributes the component below. The exact package version and
every redistributed file are stored in `THIRD-PARTY-INVENTORY.json`.

## Community.VisualStudio.Toolkit

- Package: Community.VisualStudio.Toolkit.15 (TwinCAT XAE Shell 15 build) or
